Requirements:

1. Use node 22
2. Upload images in 16:9
3. master.css on server has fixes and must be copied over when updating
4. milou build . to build the static pages
5. npx serve from the build directory to run a dev server
6. Don't forget to add the cookie consent script and google analytics on the server when updating the site
